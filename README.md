# Dhaka Tesla Pool

> Share a seat. Split the fare. Survive Dhaka traffic.

A ride-pooling MVP: passengers (Nusrat, Rafiq, Shirin) request rides, a driver (Jashim) pools
compatible requests into his three-seat Tesla (Bullet), every passenger pays an individual fare, and
seat capacity can never be exceeded — even when two people grab the last seat at the same instant.
